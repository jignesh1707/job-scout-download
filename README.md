# Job Scout — download

The job search tool for ResumeToJob students.

## Download

Go to the **Releases** tab on the right and open the latest release. Under **Assets**, download the one for your computer:

- **Windows:** `job-scout-windows.zip`
- **Mac:** `job-scout-mac.zip`

Ignore the "Source code (zip)" and "Source code (tar.gz)" files — GitHub adds those automatically and they won't work.

## Start

1. Install [Python 3.10 or newer](https://www.python.org/downloads/) (Windows: tick **"Add python.exe to PATH"** in the installer).
2. Unzip the file, then double-click **`start-windows.bat`** (Windows) or **`start-mac.command`** (Mac).
3. When asked, paste your access token from ResumeToJob (Profile → "Job scout access" → Generate token).

Your browser opens with the tool ready. Full instructions are in `HOW-TO-USE.md` inside the zip.
